# Цех — заявки на матеріали

Перша робоча версія внутрішнього вебзастосунку українською мовою.

## Запуск

Потрібен Python 3.10 або новіший. Зовнішні пакети не потрібні.

```sh
cd /workspace/2
python3 server.py
```

За замовчуванням сервер слухає `127.0.0.1:8000`. Для внутрішньої мережі можна явно задати `HOST=0.0.0.0`. Параметри: `HOST`, `PORT`, `DATABASE_PATH`. SQLite створюється автоматично; дані зберігаються між перезапусками. Для резервування працюючої бази використовуйте SQLite backup API.

## Можливості

- Пошук і категорії матеріалів, кошик, ім’я працівника, коментар, терміновість.
- Спільний список заявок зі статусами.
- Призначення постачальника для кожної позиції.
- Об’єднання однакових матеріалів у текст повідомлення для постачальника.
- Копіювання для Viber (ручне вставлення) та відкриття листа в поштовому клієнті.
- Окремі дії «Запитали ціну» та «Замовлено»; копіювання не змінює статус.
- Часткове та повне отримання, додавання матеріалів і постачальників.

Каталог початково демонстраційний. Google-таблиця не імпортована. Автоматичної відправки у Viber або пошту немає. Для копіювання браузер може вимагати HTTPS; є запасний варіант ручного копіювання.

## Межі першої версії

Авторизації та розмежування ролей ще немає: усі, хто має доступ до сервера, можуть бачити заявки й виконувати дії менеджера. Не публікуйте цей сервер у відкритий інтернет. Для робочого впровадження потрібні автентифікація, ролі, HTTPS, резервування та продуктивний сервер замість стандартного Python HTTP-сервера. Персональні сповіщення, ціни, терміни поставки, вкладення, редагування довідників та журнал змін ще не реалізовані. Для актуалізації даних перейдіть на потрібний екран або натисніть «Оновити» у заявках.

## Перевірка

```sh
python3 -m unittest discover -s tests -v
node --check static/app.js
```

Інтеграційний тест запускає тимчасовий HTTP-сервер та ізольовану базу й перевіряє створення заявки, запит ціни, замовлення, часткове/повне отримання, відхилення некоректних кількостей і довідники.

## GitHub Pages та Google Sheets

Статична версія в `static` публікується workflow `.github/workflows/pages.yml`. Без підключення вона демонстраційна та зберігає дані лише в браузері. Для спільної бази виконайте [інструкцію Google Apps Script](google-apps-script/README.md). Підключення налаштовується кнопкою на сайті. Інтеграцію з реальним Google-акаунтом ще необхідно перевірити після розгортання скрипту власником таблиці.
